# A formal model for the Online Disinhibition Effect
The reproducible code in the `/simulation` subfolder contains functions that implement one model derived from the formalized theory.
For easier navigation, the Group work folder contains collaborative documents, the Eigenarbeit ordner contains everything 
that has been created or adjusted for the individual work.


## How to reproduce the simulations:
Run the R scripts in the order of their file names (01, 02, 03)
